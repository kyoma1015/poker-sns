# Joint information / reach integration — research only

The previous postflop audit found exploitable refined-information responses even
when coarse-game NashConv was small. This implementation changes the learning
path, rather than fitting another range-weighted payoff and calling its local
equilibrium a joint solution. Existing models, ranges, demos and UI are unchanged.

`joint_reach.py/.cc` join the full existing preflop tree and each matched flop
subtree into one perfect-recall extensive game. Both seats keep their starting
169 class; after the public flop they also retain their own/public flags. Public
node identity retains the entire preflop/flop action history. Opponent actual
cards and showdown equity never enter an action key. Own suit details beyond
these flags remain abstracted; this does NOT claim to preserve all NLHE private
information. Exact joint compatible-hole mass and equity are aggregated before
any policy is applied, so changing a policy recomputes its posterior naturally.

Regret is updated by joint chance times **opponent** realization reach, with own
reach excluded. Average strategy uses own reach. Zero-own-reach branches remain
in the traversal. Synchronous iterations freeze both strategies during a sweep.
BR integrates opponent worlds and future boards BEFORE maximizing each own
preflop action. A separate Python implementation checks native BR on small games
and the actual 270-node public topology. `conditional_opponent()` exposes the
same opponent-only posterior and reports missing support explicitly.

## Artifacts / reproduction

`results.json` contains checkpoint metrics, all1690 preflop frequency/action-EV
rows per checkpoint (10 public nodes, including RFI/vs-open/vs3bet/vs4bet), exact
layout, moment fingerprints, final joint-policy fingerprint and TT conditional
opponent posteriors. Binary packets are decoded by `fullsupport.unpack`.
Each row is frequencies then counterfactual actionEV in BB, in labelled action
order; rows are NOT automatically admitted to ordinary or existing research UI.
The full final policy is generated by the command below and retained in workspace
output; CI regenerates its140325-double packet and verifies its SHA256.

```
python -B -m unittest tests.test_joint_reach -v
python -B -m gto.abstract.joint_reach_study --build-dir /tmp/joint-build --cache-dir /tmp/joint-cache --output /tmp/joint-result.json
python -B -m gto.abstract.independent_verify --actual /tmp/joint-result.json --expected docs/qa/joint-reach-20261107/results.json
```

No candidate selection after evaluation: all registered checkpoints are reported.
The initial engine/protocol were committed locally as1269f6f before fitting.
The frozen coarse baseline was added as a descriptive integration comparison
after initial16/64 traces had been observed; it was not used to choose a model or
checkpoint. Presentation/export and validation corrections were replayed before
publishing. This is local preregistration, not an external timestamp certificate.
