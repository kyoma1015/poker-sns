Baseline77fea1db32799a5f07f5680d5d0dd36fe9740532 matched the remote. New opt-in `scripts/journal_checkpoint.py` builds on PrivateJournal with a separately trusted external load/CAS contract. It does not establish trust using a head in the journal directory. The caller must authenticate and protect that external private store, guarantee durable atomic whole-value CAS and finite callback deadlines. No deployment or retained-store adapter is supplied.

The lifecycle is durable intent CAS → exact journal publication → committed pin CAS. Crash before publication resumes the trusted intent; crash after publication verifies the intent digest before pin finalization. A tail not authorized by the trusted external intent is rejected. Operation IDs are mandatory: same ID+canonical payload retries do not publish again; changed payload under an existing ID is refused. Restart/replay does not reset leases, run IDs or finite budgets.
